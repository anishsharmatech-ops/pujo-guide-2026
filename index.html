Using this guide offline

Everything here, including a basic outline map, is built into this one page. Once it has loaded, the text, lists, favourites, circuits and the outline map keep working without data; detailed street tiles appear only when online. iPhone: open it from an https web link in Safari (for example after uploading the file to your own web host) and keep the tab open. A downloaded .html file opened from Files, WhatsApp or Mail shows only a preview that can’t run the guide. Android / desktop: the saved file works in Chrome or Firefox.
